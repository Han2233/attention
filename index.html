1为什么需要注意力

Why Attention

先看翻译任务：把英文 "The cat sat on the mat" 翻译成中文「猫 坐 在 垫子 上」。老式的 Seq2Seq 模型把整句英文压缩成一个固定长度向量，再从这个向量逐词生成译文——句子一长，「压缩向量」就装不下了，就像把一本 500 页的书硬塞进一张小纸条。

人类翻译时不是这样：每写一个词，眼睛只回头看相关的原文位置——写「猫」时看 "cat"，写「坐」时看 "sat"。注意力机制把这个直觉做成数学：让模型为每个输出位置动态决定「看哪些输入位置、各看多重」。

输出词（中文）最该看的英文位置
猫cat（其余基本不看）
坐sat
在on
垫子mat
上on + mat（「在…上」拆成两个词）
本节小结
  • Seq2Seq 的固定向量是瓶颈，长句子装不下。
  • 注意力 = 动态对齐：每个输出位置有权重地「看」所有输入位置。
  • 这些权重不是人设定的，而是从数据里学出来的。

2核心直觉：注意力就是加权平均

Weighted Average

整个注意力机制可以用一句话概括：输出 = 所有「值」的加权平均，权重由「查询」和「键」的匹配程度决定。先忘掉 Transformer，用查字典的类比理解三个角色：

角色英文字典类比形状
查询Query (Q)我要查的单词（"apple" 的中文是什么？）(n_q, d_k)
键Key (K)字典里每个词条的标题(n_k, d_k)
值Value (V)每个词条的解释内容(n_k, d_v)

查询与所有键逐一「比对打分」（点积），分数经 Softmax 变成和为 1 的权重，再用权重把值加权求和——分数越高的值，对输出的贡献越大。

通俗理解你去图书馆找资料：心里带着问题（Query），书架上有贴标签的档案盒（Key），盒子里装着内容（Value）。你扫一遍标签，觉得「机器学习」盒最相关（分数高），就主要抄它的内容、顺便翻两眼「深度学习」盒——最终笔记就是所有盒子的加权平均。

3公式拆解：四步走

Scaled Dot-Product Attention

注意力（Attention Is All You Need 的原始公式）： Attention(Q, K, V) = softmax( QKT√dk ) · V
步骤运算形状含义
① 打分S = QKT(n_q, n_k)每个查询与每个键做点积（向量相似度），得到分数矩阵
② 缩放S / √d_k(n_q, n_k)除以维度的平方根，防止分数过大（见下方追问 1）
③ 归一softmax（按行）(n_q, n_k)每行变成非负、和为 1的概率分布——「看哪里、看多重」
④ 加权求和A · V(n_q, d_v)按权重把值向量加起来，得到输出
Softmax（按行作用）： softmax(z)i = ezinj=1Σ ezj
为什么是点积两个向量的点积 = 长度 × 夹角余弦，天然衡量「方向有多一致」。词向量语义越接近，点积越大——所以 Q·K 可以理解为「查询和键在语义空间里有多像」。
本节小结
  • 四步：点积打分 → 除以 √d_k → Softmax 归一 → 加权求和。
  • 只涉及矩阵乘法和指数运算——所以「Attention 全部并行、计算高效」。

5多头注意力：让多个头「各看各的」

Multi-Head Attention

一个注意力只能学到一种「看」的模式。多头（Multi-Head）把 Q、K、V 分别投影到 h 个子空间，每个头独立做注意力，最后拼接起来再投影：

多头注意力： MultiHead(Q,K,V) = Concat(head₁, …, headh)·WO   其中 headi = Attention(QWiQ, KWiK, VWiV)

直觉：像多个专家同时从不同角度读同一句话——有的头管语法相邻关系，有的头管代词指代，有的头管主谓搭配。最终把大家的意见拼起来综合。

演示 3 · 双头对比：同一个词，两个头看的位置完全不同

点击一个词，看「头 1（语法头，关注相邻词）」和「头 2（指代头，关注远距离呼应）」的权重分布差异。两个头并行独立计算，互不影响。

  • 多头 = 多个子空间各自做注意力，再拼接投影。

6掩码 Mask：让模型「不许偷看」

Padding Mask & Causal Mask

两种常见掩码：

掩码英文作用用法
填充掩码Padding Mask屏蔽 <pad> 占位符（batch 内句子长短不一）把 pad 位置的分数设为 −∞
因果掩码Causal Mask解码器自回归生成时，每个词只能看到自己及左边的词——不然就「作弊」看到未来答案了上三角分数设为 −∞

实现手法统一：把被禁止位置的分数设成 −∞，Softmax(e^(−∞)) = 0，权重自然归零。

演示 4 · 因果掩码（GPT 生成式注意力）

句子 "I love cyber security"。勾选「应用因果掩码」前后对比：没有掩码时每个词都看全句（双向，BERT 模式）；加上掩码后每个词只能看自己和左边的词（GPT 模式）。注意第一行只剩自己一个词，权重 100%。

本节小结
  • 掩码 = 把禁止位置的分数设为 −∞，Softmax 后权重为 0。
  • 因果掩码 = 下三角矩阵，保证「只看过去、不看未来」。
  • 面试必问：mask 怎么实现——一句话「加 −inf」。

8面试手撕代码

Implement Attention from Scratch

面试官最爱让候选人手写「缩放点积注意力」甚至完整的多头注意力。写作顺序建议：① 先口述公式 Attention(Q,K,V)=softmax(QKᵀ/√d_k)V；② 讲清四个关键细节（缩放、Softmax、数值稳定、mask）；③ 再动手写代码。

8.1 NumPy 版：缩放点积注意力

# 手撕 1：缩放点积注意力（NumPy 版） import numpy as np def attention(Q, K, V, mask=None): # Q: (n_q, d_k) K: (n_k, d_k) V: (n_k, d_v) 输出: (n_q, d_v) d_k = Q.shape[-1] # ① 打分：Q 与 K 点积（transpose(-2,-1) 把 K 转置） scores = Q @ K.transpose(-2, -1) / np.sqrt(d_k) # ② mask：被禁止位置置 -1e9（≈ -inf），Softmax 后权重为 0 if mask is not None: scores = np.where(mask == 0, -1e9, scores) # ③ Softmax（减去每行最大值，防止 e^x 溢出——数值稳定技巧） exp_scores = np.exp(scores - scores.max(axis=-1, keepdims=True)) attn_weights = exp_scores / exp_scores.sum(axis=-1, keepdims=True) # ④ 加权求和 output = attn_weights @ V return output, attn_weights

8.2 PyTorch 版：完整多头注意力

# 手撕 2：多头注意力（PyTorch 版，面试常考） import torch import torch.nn as nn import math class MultiHeadAttention(nn.Module): def __init__(self, d_model, n_heads): super().__init__() assert d_model % n_heads == 0 self.d_k = d_model // n_heads # 每个头的维度 self.n_heads = n_heads # 四个投影矩阵（也可合并成一个 Linear(d_model, 3*d_model)） self.Wq = nn.Linear(d_model, d_model) self.Wk = nn.Linear(d_model, d_model) self.Wv = nn.Linear(d_model, d_model) self.Wo = nn.Linear(d_model, d_model) # 拼接后的输出投影 def forward(self, x, mask=None): B, T, _ = x.shape # batch, 序列长, 维度 # 投影并切成多头：(B, T, d_model) -> (B, n_heads, T, d_k) Q = self.Wq(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2) K = self.Wk(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2) V = self.Wv(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2) # 打分 + 缩放：(B, n_heads, T, T) scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k) if mask is not None: scores = scores.masked_fill(mask == 0, float('-inf')) attn = scores.softmax(dim=-1) # 按行归一 out = attn @ V # 加权求和 # 拼回头并输出投影：(B, n_heads, T, d_k) -> (B, T, d_model) out = out.transpose(1, 2).contiguous().view(B, T, -1) return self.Wo(out), attn

8.4 复杂度速算

注意力权重矩阵是 n×n，每个元素一次点积 O(d) → 总复杂度 O(n²·d)。序列长度 n 翻倍，计算量翻四倍——这就是「长上下文贵」的根源，也是 FlashAttention、稀疏注意力、线性注意力诞生的原因。

本节小结
  • 手撕三件套：注意力（NumPy）、多头（PyTorch）、因果掩码（tril）。
  • 四个必须写出来的细节：÷√d_k、mask 加 −inf、softmax 减 max、维度变换。
  • 复杂度 O(n²d)，面试可能追问如何优化。

9面试追问清单

Follow-up Questions

追问参考回答
为什么除以 √d_k？d_k 很大时点积方差随维度线性增长，分数绝对值变大 → Softmax 进入饱和区（权重接近 one-hot），梯度趋近 0。除以 √d_k 把方差压回 1，让 Softmax 保持「软」。
为什么用 Softmax？① 非负、② 每行和为 1（天然的概率解释）、③ 处处可导、④ 指数放大差异让「相关」和「不相关」拉开距离。
Softmax 前为什么要减 max？数值稳定：分数很大时 e^z 直接溢出为 inf。Softmax(z) = Softmax(z − max) 结果不变，但指数项落在安全范围。
mask 怎么实现？被禁止位置加 −inf（实现上常加 −1e9），Softmax 后权重精确为 0。
多头有什么好处？不同头在不同子空间学不同关系（语法/指代/位置），模型表达能力更强；总计算量不变（维度被切分）。
自注意力与交叉注意力的区别？Q、K、V 同源为自注意力（句内关系）；Q 来自解码器、K/V 来自编码器为交叉注意力（对齐）。
注意力需要位置编码吗？需要。注意力是「集合运算」，对词序不敏感（打乱输入行，输出行跟着打乱——置换等变）；位置信息靠位置编码显式注入。
复杂度是多少？长序列怎么办？O(n²d)。优化方向：稀疏注意力（Longformer）、线性注意力（Performer）、分块/IO 优化（FlashAttention）、KV Cache 加速推理。
推理时 KV Cache 是什么？自回归生成时，前面 token 的 K、V 每次都被重算。把它们缓存起来，每个新 token 只算新增的 Q·K——把每步 O(n²) 降到 O(n)。
训练时注意什么？对注意力权重加 dropout；配合 warmup 学习率与梯度裁剪（Transformer 训练易不稳定）。
本节小结
  • 核心追问绕不开：√d_k、Softmax、mask、复杂度、KV Cache。
  • 回答公式：先说「一句话结论」，再补「为什么」，最后举一个例子。
